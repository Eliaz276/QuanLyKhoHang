
# PHAN MEM QUAN LY KHO HANG

## 1. Gioi thieu
Phan mem quan ly kho hang duoc xay dung bang Java Swing
va ket noi voi SQL Server.

## 2. Cong nghe su dung
- Java
- Java Swing
- SQL Server 2025 Express
- JDBC
- Maven
- NetBeans IDE

## 3. Cac chuc nang
- Dang nhap he thong.
- Quan ly loai hang.
- Quan ly nha cung cap.
- Quan ly hang hoa.
- Them, sua, xoa va tim kiem du lieu.

## 4. Co so du lieu
Ten database: QuanLyKhoHang

Cac bang:
- LOAIHANG
- NHACUNGCAP
- HANGHOA
- TAIKHOAN

## 5. Cau truc chuong trinh
- QuanLyKhoHang.java: Chay chuong trinh.
- KetNoi.java: Ket noi SQL Server.
- FormDangNhap.java: Dang nhap.
- FormChinh.java: Man hinh chinh.
- FormLoaiHang.java: Quan ly loai hang.
- FormNhaCungCap.java: Quan ly nha cung cap.
- FormHangHoa.java: Quan ly hang hoa.

## 6. Huong dan cai dat
1. Cai dat JDK va SQL Server.
2. Mo SQL Server Management Studio.
3. Chay file database/QuanLyKhoHang.sql.
4. Mo project bang NetBeans.
5. Kiem tra thong tin ket noi trong KetNoi.java.
6. Chay class QuanLyKhoHang.
